# FakeLess - AI-Generated Image Detection System

**FakeLess** is an AI-powered system designed to identify image forgery, tampering, and AI-generated content. Built as a Computer Science graduation project, it provides reliable verification to ensure digital image authenticity.

---

## 📌 Features
- **AI Forgery Detection:** Analyzes images to detect synthetic manipulation and deepfake artifacts.
- **Image Processing Pipeline:** Applies advanced image analysis algorithms to flag altered regions.
- **User-Friendly Interface:** Allows users to easily upload and inspect images for authenticity.

---

## 🛠️ Tech Stack
- **Backend:** Python, PHP
- **Frontend:** HTML, CSS, JavaScript
- **Core Focus:** Computer Vision, Machine Learning, Image Integrity Analysis

---

## 🚀 How It Works
1. Upload an image to the system.
2. The detection pipeline processes the image using analysis models.
3. The system returns an authenticity result highlighting potential manipulations.
