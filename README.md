# FakeLess - AI-Generated Image Detection System

**FakeLess** is an AI-powered system designed to identify image forgery, tampering, and AI-generated content. Developed as a Computer Science graduation project in a team of 8 students, it provides reliable verification to ensure digital image authenticity.

---

## 📌 Features
- **AI Forgery Detection:** Analyzes images to detect synthetic manipulation and deepfake artifacts.
- **Image Processing Pipeline:** Applies advanced image analysis algorithms to flag altered regions.
- **User-Friendly Web Interface:** Allows users to easily upload and inspect images for authenticity.

---

## 🛠️ Tech Stack
- **Backend:** Python, PHP
- **Frontend:** HTML5, CSS3, JavaScript
- **Core Focus:** Computer Vision, Machine Learning, Image Integrity Analysis
